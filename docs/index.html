Useful code context, with evidence.

A fast local code-intelligence layer that gives coding agents fresh, reproducible context from the current worktree within a token budget. It is a retrieval backend, not a desktop IDE and not an embedded LLM.

Fresh

The response identifies the indexed generation, commit, dirty-worktree fingerprint, and staleness.

Trustworthy

Evidence includes source coordinates, origin, confidence, and an explicit reason for inclusion.

Efficient

get_context packs focused snippets and traces into the caller's token budget.

Install only where you ask

Registration is client-scoped. Existing indexes remain intact; hooks and instruction files are opt-in. 

codebase-memory-mcp install --client codex
codebase-memory-mcp setup . --client codex

# Optional:
codebase-memory-mcp setup . --client codex --no-watch
codebase-memory-mcp setup . --client codex --with-hooks

A small default MCP surface

The standard toolset contains the operations coding agents use most:

  • get_context, search_graph, and search_code
  • trace_path, get_code_snippet, and get_architecture
  • detect_changes, index_status, and index_repository

Arbitrary graph queries, ADR and cross-repository features are advanced; project administration is a separate explicit toolset.

Language quality is tiered

  • Core targets: Go, Python, JavaScript/TypeScript, Java, C/C++, and Rust.
  • Preview static resolvers: C#, PHP, and Kotlin.
  • Structural: other bundled Tree-sitter grammars, best effort only.

“Static resolver” is intentional terminology: the project does not implement the JSON-RPC Language Server Protocol. Lean and the dedicated SystemVerilog parser are not part of the current build; .sv uses the experimental Verilog structural fallback.

Claims require artifacts

Performance, accuracy, and token-efficiency results are published only with pinned repositories, commits, hardware, tool versions, raw responses, and traces. Historical study results are available in the project preprint; they are not blanket guarantees for the current worktree or every language.
