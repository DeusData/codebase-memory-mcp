## 1. Executive Summary & Problem Statement

### 1.1 The Problem
In real-world software engineering, code duplication is one of the most persistent sources of technical debt, maintenance overhead, and security vulnerabilities:
1. **Copy-Paste Bugs:** A bug is discovered and fixed in one function, but identical copy-pasted implementations in other files remain unpatched.
2. **Reinventing the Wheel:** Developers and AI assistants frequently write new helper functions (e.g., string sanitization, token splitting, hash verification) without realizing an almost identical implementation already exists in another module.
3. **Refactoring Opportunities:** Teams preparing for library extraction or modularization need to find clusters of duplicate logic across disparate directories.

Currently:
- `codebase-memory-mcp` already runs a sophisticated **MinHash AST fingerprinting pipeline** ([`src/pipeline/pass_similarity.c`](file:///c:/AI/Source/codebase-memory-mcp-ui/src/pipeline/pass_similarity.c)), computing 64-bit structural hashes, body tokens, and struct profiles.
- This pass has already populated **17,341 `SIMILAR_TO` edges** and **1,444 `SEMANTICALLY_RELATED` edges** in the SQLite database!
- **However, not a single MCP tool exposes this capability to agents or developers.** The entire 17,000+ edge similarity graph sits dormant, unusable unless someone manually writes custom Cypher queries.

### 1.2 The Solution
Introduce `find_code_clones`.
This tool unlocks the pre-computed similarity graph to:
- Find all structural and semantic clones of a target function or method.
- Scan an entire project or directory for the most egregious duplicate code clusters.
- Compare similarity scores, highlight matching token structures, and provide consolidation recommendations.

## 4. Query Architecture & C Implementation

### 4.1 Finding Clones for a Target Symbol

```sql
SELECT 
    target.id,
    target.name,
    target.qualified_name,
    target.file_path,
    target.start_line,
    target.end_line,
    e.type AS edge_type,
    coalesce(cast(json_extract(e.properties, '$.similarity') AS REAL), 0.80) AS sim_score,
    json_extract(target.properties, '$.signature') AS signature
FROM edges e
JOIN nodes target ON e.target_id = target.id
WHERE e.project = ?1
  AND e.source_id = ?2
  AND e.type IN ('SIMILAR_TO', 'SEMANTICALLY_RELATED')
  AND coalesce(cast(json_extract(e.properties, '$.similarity') AS REAL), 0.80) >= ?3
ORDER BY sim_score DESC
LIMIT ?4;
```

### 4.2 Project-Wide Top Duplicate Clusters

```sql
SELECT 
    n1.qualified_name AS symbol_a,
    n1.file_path AS file_a,
    n2.qualified_name AS symbol_b,
    n2.file_path AS file_b,
    cast(json_extract(e.properties, '$.similarity') AS REAL) AS sim,
    e.type
FROM edges e
JOIN nodes n1 ON e.source_id = n1.id
JOIN nodes n2 ON e.target_id = n2.id
WHERE e.project = ?1
  AND e.type = 'SIMILAR_TO'
  AND n1.file_path != n2.file_path
  AND cast(json_extract(e.properties, '$.similarity') AS REAL) >= ?2
ORDER BY sim DESC
LIMIT ?3;
```

## 5. CLI & UI Integration

### 5.1 CLI Command
```bash
# Find all clones of a function
cbm cli find_code_clones --project codebase-memory-mcp-ui --target src.mcp.mcp.heap_strdup

# Find highest-similarity cross-file duplicates across repo
cbm cli find_code_clones --project codebase-memory-mcp-ui --min-similarity 0.90 --limit 15
```

### 5.2 UI Integration (`graph-ui`)
- **NodeDetailPanel**:
  - Add a **"👯 Clones & Duplicates"** tab.
  - Lists similar functions with a visual side-by-side diff snippet and similarity pill (`96% match`).
- **GraphScene 3D View**:
  - Toggle "Show Clone Edges" to draw dotted purple lines (`#c084fc`) between duplicate functions in 3D space.
